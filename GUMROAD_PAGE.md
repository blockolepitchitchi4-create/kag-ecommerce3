Description longue:
KAG E‑commerce est un template e‑commerce professionnel construit en TypeScript. Il combine :
- une interface frontend réactive (React + Tailwind),
- des exemples de pages produits et panier,
- une architecture backend orientée Cloudflare Workers & Workflows pour la gestion asynchrone des commandes,
- une démo temps‑réel via WebSocket et Durable Objects.

Ce pack vous permet de lancer une boutique de démonstration, de comprendre un flux de commande moderne et d'adapter le code pour un projet commercial ou un client.

Installation rapide (à coller dans la section « Instructions » ou README)
1. Télécharger et extraire l’archive.  
2. Dans le dossier racine :
   - npm install
   - npm run build
3. Lancer en local : npm run dev  
4. Déployer : connectez le repo à Vercel/Netlify ou utilisez Wrangler pour Cloudflare Workers (voir README pour détails).
